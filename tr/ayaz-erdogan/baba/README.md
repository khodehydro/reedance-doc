# Baba — Ayaz Erdoğan ft. Mengelez

[فایل خام آموزشی `baba.rddraft.json`](./baba.rddraft.json)

## محتوا

| بخش | تعداد |
| --- | ---: |
| سطرهای لیریک، با حفظ تکرارها | 63 |
| واژگان (شامل عددهای یک تا ده) | 117 |
| فعل‌های دارای جدول صرف | 37 |
| نکتهٔ گرامری | 21 |
| اصطلاح و جملهٔ تمرینی مستقل | 6 اصطلاح + 6 جمله |
| جدول واژگان مرتبط | 4 |
| پرسش | 16؛ چهار نوع، هر نوع چهار پرسش |

هر سطر ترجمهٔ فارسی و انگلیسی و توکن‌های متناظر دارد. مثال هر واژه، مثال‌های گرامر و جمله‌های تمرینی **جمله‌هایی تازه خارج از لیریک** هستند. جدول‌های هر فعل، صورت‌های شش‌شخصیِ زمان/وجه و قطبیت موجود در متن و نیز حال گستردهٔ مثبت را نشان می‌دهند؛ صورت معیار برای نوشتار شکسته به کار رفته است. برای امر، اول‌شخص واقعاً وجود ندارد و با «ندارد» مشخص شده است؛ مصدر، صفت‌فعلی و فعل‌قید را نیز به‌اشتباه فعل شخص‌دار فرض نکرده‌ایم.

## نکته‌های این درس

- عنوان‌های بخش‌ها، مشخصات آغازین سایت و بخش پیشنهاد آهنگ حذف شده‌اند؛ صداهای همراه مانند `(Ey)` حفظ شده‌اند. سطرهای تکراری برای همگام‌سازی آینده جدا هستند.
- `kardeş` بدون تعیین جنسیت است؛ `kırk` و `bir karış` در این بافت می‌توانند اغراق باشند. خانواده، بدن و عددهای یک تا ده جداگانه تمرین می‌شوند.
- اتصال معنایی بعضی جمله‌های شاعرانه، از جمله `Dert oluyor millete mert`، مبهم است و ترجمه به‌عنوان برداشت احتمالی معرفی شده است. `sarılıca’m` با شکل معیار `sarılacağım` توضیح داده می‌شود.

## استفاده و محدودیت

این فایل `UTF-8` خام و بدون صوت، تصویر و زمان‌بندی است؛ `level` نیز چون ارائه نشده حذف شده است. متن ارسالی سند مجوز نداشت و وضعیت حقوق متن و صوت `unverified` است. برای انتشار، بررسی حقوق، تعیین سطح، انتخاب صوت و زمان‌بندی تک‌تک سطرها در Studio لازم است؛ از این پیش‌نویس به‌تنهایی `.rdpack` آماده ساخته نشده است.
